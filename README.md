# Sistema de Estoque em Python

Sistema de gerenciamento de estoque desenvolvido em Python com foco na prática de lógica de programação, organização de código e orientação a objetos.

O projeto permite cadastrar produtos e realizar operações de controle de estoque diretamente pelo terminal.

## Funcionalidades

- Cadastro de produtos
- Listagem dos produtos cadastrados
- Busca de produtos
- Entrada de itens no estoque
- Saída de itens do estoque
- Consulta do valor total do estoque
- Validação das opções informadas pelo usuário

## Tecnologias utilizadas

- Python
- Programação Orientada a Objetos (POO)
- Git
- GitHub

## Como executar

Para executar o projeto, é necessário ter o Python instalado no computador.

Após baixar ou clonar o projeto, abra o terminal na pasta do sistema e execute:

```bash
python main.py
```

No Windows, caso o comando `python` não esteja disponível, utilize:

```bash
py main.py
```

## Estrutura do projeto

O sistema utiliza uma classe para representar os produtos e funções responsáveis pelas principais operações de gerenciamento do estoque.

Os dados são mantidos durante a execução do programa.
